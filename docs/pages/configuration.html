Configuration

Server settings via server.toml with sensible defaults.

Getting Started

MC-RS uses a single server.toml file for all configuration. On first run, the server automatically generates a default server.toml in the working directory with sensible defaults. You can then edit it and restart the server to apply changes.

Tip: The server reads server.toml from the current working directory at startup. If the file does not exist, it is created automatically with all default values.

Full Configuration Example

Here is a complete server.toml with all available options and their default values:

# ===========================================
# MC-RS Server Configuration
# ===========================================

[server]
motd = "MC-RS Server"          # Server name shown in the server list
sub_motd = "Powered by Rust"   # Sub-title shown below the MOTD
port = 19132                    # UDP port to listen on
max_players = 20               # Maximum concurrent players
online_mode = false            # Xbox Live authentication
view_distance = 8              # Chunk render distance (in chunks)
tick_rate = 10                 # Milliseconds per server tick

[world]
name = "world"                 # World directory name
generator = "flat"             # World generator type
seed = 0                       # World seed (0 = random)

[gameplay]
gamemode = "creative"          # Default game mode for new players
difficulty = "normal"          # World difficulty
pvp = true                     # Player vs Player combat
do_daylight_cycle = true      # Day/night cycle progression
do_weather_cycle = false      # Weather changes over time
spawn_protection = 16         # Spawn area protection radius

[server] Section

Controls the network-facing server settings and performance parameters.

OptionTypeDefaultDescription
motd String "MC-RS Server" The server name displayed in the Minecraft server list. Supports standard text (no color codes).
sub_motd String "Powered by Rust" Secondary line shown below the MOTD in the server list.
port Integer 19132 UDP port the server listens on. The default 19132 is the standard Bedrock port. Clients on the same LAN will auto-discover the server on this port.
max_players Integer 20 Maximum number of players that can be connected simultaneously. Additional connections are rejected.
online_mode Boolean false When true, the server verifies Xbox Live authentication tokens during login. When false, any player name is accepted (cracked mode).
view_distance Integer 8 Chunk render distance in chunks. Higher values increase the visible area but require more memory and bandwidth. Typical values: 4 (low), 8 (medium), 16 (high).
tick_rate Integer 10 Milliseconds between server ticks. Lower values mean faster updates but higher CPU usage. The default of 10ms gives 100 ticks per second.

[world] Section

Controls world generation and storage.

OptionTypeDefaultDescription
name String "world" Directory name where world data is stored. The server creates this directory if it does not exist.
generator String "flat" World generator type. Valid values: "flat" (superflat world with grass, dirt, and bedrock layers) or "terrain" (Perlin noise hills with dynamic terrain generation).
seed Integer 0 Seed for world generation. A value of 0 generates a random seed at startup. The same seed always produces the same terrain.
Generator types: The flat generator creates a classic superflat world ideal for building and testing. The terrain generator uses Perlin noise to create rolling hills with varied elevation, suitable for survival gameplay.

[gameplay] Section

Controls in-game rules and mechanics.

OptionTypeDefaultDescription
gamemode String "creative" Default game mode for new players. Valid values: "survival", "creative", "adventure", "spectator".
difficulty String "normal" World difficulty level. Valid values: "peaceful", "easy", "normal", "hard".
pvp Boolean true Whether players can damage each other. When false, player-to-player combat is disabled.
do_daylight_cycle Boolean true Whether the day/night cycle progresses automatically. When false, time stays fixed at whatever value was last set.
do_weather_cycle Boolean false Whether weather changes occur automatically. When false, weather stays clear unless changed with /weather.
spawn_protection Integer 16 Radius (in blocks) around the world spawn point where non-operator players cannot break or place blocks.

File Locations

MC-RS uses the following files and directories relative to the working directory:

PathDescription
server.toml Main configuration file. Auto-created on first run with default values.
players/ Player data directory. Stores per-player state (position, inventory, game mode) as individual files keyed by player name or XUID.
Important: Changes to server.toml require a server restart to take effect. The server does not hot-reload configuration.
