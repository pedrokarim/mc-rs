Overview

MC-RS is a from-scratch Minecraft Bedrock Edition server written in Rust, based on the PocketMine-MP reference implementation.

What is MC-RS?

MC-RS is a Minecraft Bedrock Edition server written entirely in Rust. It targets protocol version 924 (Bedrock Edition 1.26.2) and is a clean rewrite based on PocketMine-MP as the reference implementation.

The server currently handles the full connection lifecycle: RakNet UDP transport, ECDH encryption handshake, Xbox Live JWT login (with offline mode), zlib/snappy compression, chunk streaming, player movement, chat, commands, and multi-player synchronization. Players can connect with an unmodified Bedrock client and join a generated world together.

Note: MC-RS is a clean-room implementation. It does not use or depend on Mojang's official server code (BDS). All protocol handling is implemented from the PocketMine-MP source code and packet analysis.

What Works Today

  • RakNet UDP transport with reliability, fragmentation, and ordering
  • ECDH P-384 key exchange + AES-256-CTR packet encryption
  • Xbox Live JWT authentication chain + offline mode
  • Zlib and Snappy batch compression
  • Flat world generator and Perlin noise terrain generator
  • Sub-chunk paletted storage with biome serialization
  • Multi-player support: AddPlayer, RemoveEntity, PlayerList broadcasts
  • Player movement synchronization across clients
  • Chat relay between players
  • 16 built-in commands: help, list, tp, gamemode, say, time, kill, stop, ping, seed, pos, difficulty, weather, spawn, up, clear
  • Day/night cycle with time ticking
  • Weather cycle (clear, rain, thunder)
  • Player persistence via JSON files in the players/ directory
  • Dynamic spawn position based on terrain height
  • Server configuration via server.toml (server, world, gameplay sections)

Why Rust?

Performance

Compiled to native code with zero-cost abstractions. No garbage collector pauses, no JIT warmup. Chunk generation and packet processing run at full speed from the first tick.

Memory Safety

Rust's ownership system eliminates use-after-free, double-free, buffer overflows, and data races at compile time. No null pointer exceptions, no segfaults in production.

Fearless Concurrency

Send and Sync traits prevent data races. Combined with tokio's async runtime, MC-RS handles concurrent connections without thread-safety bugs.

Type System

Rust's expressive type system catches protocol encoding bugs, invalid state transitions, and missing packet fields at compile time rather than in production.
