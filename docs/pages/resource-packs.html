Resource Packs & Custom UI

Server-driven resource-pack delivery plus 8 custom form layouts via a title-flag UI dispatcher.

MC-RS serves a resource pack to every client at join time and uses it to render custom form layouts — without leaving the standard Bedrock ModalForm API.

Delivery pipeline

  1. At boot, each folder under resource_packs/ is zipped in memory (deflate) and its SHA-256 computed.
  2. At login the server sends ResourcePacksInfo (with must_accept).
  3. The client downloads the pack chunk by chunk (1 MB chunks) and verifies the SHA-256.
  4. The server sends ResourcePackStack; once the client confirms, gameplay begins and the pack's UI overrides are active.

Title-flag dispatcher

Bedrock only has three official form types (form, modal, custom_form). To get visually distinct layouts, the server injects an invisible flag into the form title; the pack reads it and renders a different layout.

title: "§m§f §6Welcome!"   // §m§f selects the MOTD layout
        │
        ▼
server_form.json  →  matches the flag  →  renders mcrs_motd_modal

The 8 layouts

FlagLayoutUse case
§m§agridAction menu (default)
§m§bleft_buttonSettings, two-panel navigation
§m§cbottom_buttonGame-mode showcase
§m§dimage_gridMap / arena picker
§m§esquare_imageSquare image announcement
§m§fmotdMessage of the day
§m§0storeShop with category tabs
§m§1wrappedRecap with scrolling images

Try it in-game

/menu            # hub menu
/menu showcase   # list all 8 layouts
/menu motd       # open a specific layout directly
Full guide: the complete pipeline reference and a step-by-step "create your own layout" tutorial live in the developer docs: Resource Pack & Custom UI.
