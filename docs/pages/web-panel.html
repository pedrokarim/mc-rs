Web Admin Panel

A built-in web dashboard (the mc-rs-webui crate) for monitoring and administering the server.

When [webui] enabled = true, the server starts an Axum HTTP server (default http://127.0.0.1:8080) as a separate tokio task. It reads a shared snapshot the game loop pushes ~20 times per second, so it never blocks gameplay.

Features

AreaDescription
DashboardLive metrics (TPS, players, memory, uptime) streamed over WebSocket.
ConsoleRun server commands and stream log output from the browser.
PlayersView connected players and act on them.
UsersManage panel accounts and roles (admin / moderator).
WorldInspect world state and configuration.
Audit logRecord of administrative actions.

Authentication

Login is JWT-based with Argon2-hashed passwords, rate limiting on the login route, and a configurable session lifetime (session_duration_hours). On first run the panel guides you through creating the initial admin account.

Storage backends

The panel persists users and the audit log via a pluggable database layer. SQLite is the default (sqlite://webui.db); Postgres and MongoDB backends are planned.

Configuration

[webui]
enabled = true
bind = "127.0.0.1:8080"      # use 0.0.0.0 to expose on the network
database_url = "sqlite://webui.db"
session_duration_hours = 24

[webui.tls]
enabled = false             # serve over HTTPS
cert_path = ""
key_path = ""
Exposing the panel: bind to 0.0.0.0 only behind TLS and a strong admin password. The panel is an administrative surface — treat it like SSH.

See Configuration for the full option reference.
