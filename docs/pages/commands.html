Commands

16 built-in server commands with relative coordinates and game mode support.

Command Reference

All commands are prefixed with / and executed from the in-game chat. Arguments in <angle brackets> are required, arguments in [square brackets] are optional.

CommandSyntaxDescription
/help/help [command]Show available commands or details about a specific command
/list/listShow all online players
/tp/tp <x> <y> <z>Teleport to coordinates (supports ~ relative coords)
/gamemode/gamemode <0-3|name>Change your game mode
/say/say <message>Broadcast a message to all players
/time/time set <value>Set the world time
/kill/killKill yourself
/stop/stopStop the server
/ping/pingShow your current ping to the server
/seed/seedShow the world seed
/pos/posShow your current position
/difficulty/difficulty <0-3|name>Set the world difficulty
/weather/weather <type>Set the weather
/spawn/spawnTeleport to world spawn point
/up/up [blocks]Teleport up N blocks (default: 1)
/clear/clearClear your inventory

CommandAction System

Each command handler returns a CommandAction enum that tells the server what side-effect to perform. This decouples command parsing from execution:

enum CommandAction {
    Teleport(x, y, z),      // Move the player to absolute coordinates
    SetGamemode(mode),       // Change the player's game mode
    Broadcast(message),      // Send a message to all players
    Stop,                    // Shut down the server
    SetTime(ticks),          // Set the world time
    SetWeather(weather),     // Change the weather
    Kill,                    // Kill the executing player
    None,                    // No side-effect (info commands)
}

Commands like /ping, /pos, /seed, /list, and /help send a chat message back to the player and return None. Action commands like /tp or /gamemode return the appropriate variant so the server can apply the change.

Relative Coordinates

The /tp command supports Minecraft's tilde (~) notation for relative coordinates. Each axis can independently be absolute or relative to the player's current position:

ExampleMeaning
/tp 100 64 200Teleport to absolute position (100, 64, 200)
/tp ~ ~10 ~Teleport 10 blocks up from current position
/tp ~5 ~ ~-3Move 5 blocks on X, stay at same Y, move -3 on Z
/tp ~ 100 ~Keep X and Z, set Y to 100
Tip: Using ~ alone (without a number) is equivalent to ~0 — it keeps the player's current coordinate on that axis.

Game Modes

The /gamemode command accepts either a numeric ID or a name:

IDNameDescription
0survivalSurvival mode — gather resources, health, hunger
1creativeCreative mode — unlimited blocks, flying, no damage
2adventureAdventure mode — cannot break/place blocks freely
3spectatorSpectator mode — invisible, fly through blocks

Time Values

The /time set command accepts named presets or a numeric tick value (0–24000):

PresetTick ValueDescription
day1000Early morning, sun is up
noon6000Midday, sun at highest point
sunset12000Sun setting, mobs begin spawning
night13000Night time, full darkness

You can also pass any integer value directly: /time set 18000 sets midnight.

Difficulty Levels

The /difficulty command accepts either a numeric ID or a name:

IDNameDescription
0peacefulNo hostile mobs, health regenerates
1easyHostile mobs deal less damage
2normalStandard difficulty
3hardHostile mobs deal more damage, hunger can kill

Weather Types

The /weather command accepts one of three weather types:

TypeDescription
clearClear skies, no precipitation
rainRain (or snow in cold biomes)
thunderThunderstorm with lightning
Note: Weather changes require do_weather_cycle to be enabled in the server configuration, or the weather will reset on the next cycle tick.
