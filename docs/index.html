Key Features

RakNet & Encryption

Full RakNet UDP transport with ECDH P-384 key exchange and AES-256-CTR encryption.

Login Flow

Xbox Live JWT authentication chain verification with offline mode support.

World Generation

Simplex 3D terrain with biomes, ores, trees and structures, plus a flat generator. LevelDB-backed chunk persistence.

Multi-Player

Player sync with AddPlayer/RemoveEntity broadcasts, PlayerList updates, and chat relay.

65 Commands

Vanilla command set with tab-complete: /tp, /gamemode, /fill, /clone, /scoreboard, /effect, /enchant, /summon, and more.

Lua Plugins

plugin.yml manifests, Lua 5.4 scripting (mlua), event hooks, a tick scheduler, and custom command registration.

Web Admin Panel

Built-in dashboard (mc-rs-webui): live metrics over WebSocket, console, player/user management, world view, audit log, JWT auth.

Resource Packs & UI

Server-driven resource pack pipeline plus 8 custom form layouts via a title-flag UI dispatcher.

Quick Start

# Clone and build
git clone https://github.com/pedrokarim/mc-rs.git
cd mc-rs
cargo build --release

# Start the server
cargo run --release

The server creates a default server.toml on first run. See Configuration for all options.

Workspace Crates

The workspace is split into 7 crates (~90K lines of Rust). World generation, entities, and gameplay all live inside mc-rs-server.

CrateDescription
mc-rs-serverMain binary: tokio runtime, connection state machine, game loop, world generation & persistence, entities, gameplay systems, commands, plugins, RCON/Query
mc-rs-protoPacket encoding/decoding, VarInt/VarUInt codec, batch compression (zlib/snappy), Bedrock packet types
mc-rs-raknetRakNet UDP transport: reliability, fragmentation, ordering, ACK/NACK, unconnected ping/MOTD
mc-rs-cryptoECDH P-384 key exchange, AES-256-CTR packet encryption, JWT parsing and chain verification
mc-rs-nbtNBT little-endian (disk) and network (ZigZag VarInt) variants, all tag types
mc-rs-commandGeneric command engine: registry, parser, permissions, entity selectors, typed arguments
mc-rs-webuiWeb admin panel: Axum server, JWT auth, SQLite backend, live metrics over WebSocket, audit log
